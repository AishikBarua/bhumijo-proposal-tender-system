Email settings

Automatically read tender alert emails and run them through Stages 1-4 (classify, parse, screen for relevance, preliminary fit score). Final eligibility is still a human decision - see the "Needs review" bucket on the dashboard.
This needs a Zoho App Password, not the normal account password.
  1. Confirm IMAP Access is enabled for this account: Zoho Mail Settings → Mail Accounts → IMAP.
  2. Go to accounts.zoho.com → Security → App Passwords and generate a new one (name it something like "Tender Agent").
  3. Open bhumijo_system\.env in Notepad and paste it after IMAP_APP_PASSWORD= (no quotes, no spaces), then restart the server. A system environment variable of the same name also works and takes priority. It is not entered on this page, so it never sits in this app's database. (The old GMAIL_APP_PASSWORD name still works but is deprecated.)
